Common questions

Adding books. Open the Files app, go to On My iPhone → Myna, and make a folder — that folder becomes a shelf. Put each audiobook in its own folder inside it. Full instructions are also in the app itself, under Admin.

The admin passcode. If it's forgotten, the only way back in is deleting and reinstalling the app, which loses the shelves, saved places and anything kept from the transcript. There is no remote reset, because MynaBooks has no account and no server to reset it from.

Voice commands not understood. Admin's usage report lists phrases MynaBooks could not understand, which is the best way to tell us what to improve.
